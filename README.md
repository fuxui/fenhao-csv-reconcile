# 分毫 · 本地 CSV 对账

**双击 `index.html` 即可使用。** ZIP 先完整解压，再打开其中的 `index.html`。推荐现代 Edge、Chrome 或 Firefox；不需要安装、启动服务器、账号或网络。请保留同目录下 `core.js`、`app.js`、`style.css`。

## 三步使用

1. 可先点「载入合成样例并对账」体验。样例是编造数据，不会读取您的财务文件。
2. 分别选择账单 A、B 的 CSV，检查编号列和金额列，展开原始记录预览。确认第一行是标题、金额为人民币后，点「开始对账」。
3. 查看「金额不同」「仅 A 有」「仅 B 有」「一致」，核对原始行号。导出全部差异 CSV，或导出包括一致记录的全部结果。

换文件、换列映射或取消标题确认，会立即清除旧结果。重置或刷新会清空内存中的账单。原文件始终只读；工具不会自动合并或修正数据。

## 输入范围与规则

- 只支持 UTF-8 / UTF-8 BOM CSV。GBK、ANSI、Excel `.xlsx` 不支持。可用可信本地工具另存为 UTF-8 CSV。
- 每份最多 10,000 条数据记录（不含标题）及 10 MiB。空白记录也需要清理，不能夹入记录中。
- 第一行必须是至少两列非空且不重复的标题。工具不能可靠判断一行究竟是标题还是数据，请检查预览和确认框；没有标题的两列文件不能自动可靠检出。
- CSV 支持中文标题、引号、逗号、CRLF / LF / CR 和引号内换行。字段包含逗号或换行须加双引号，内部引号写为两个双引号。
- 编号按文本比较，只去首尾空白。`001` 与 `1` 不同；大小写不同也不同。
- 单币种人民币。金额可带 `+` 或 `-`、最多两位小数，使用整数分 / BigInt 计算。不接受千分位、科学计数、币种符号、小数点后无数字。单笔绝对值最多 `9999999999999999.99` 元。合计可以超过单笔上限并保持精确。
- 空编号、重复编号、非法金额、CSV 格式错误会显著报错并阻止结果和导出。数据错误最多展示前 100 处，显示完整数量。请人工检查副本后重新选择。

## 结果和导出

行号是 CSV 原文的物理行号，标题为第 1 行；引号中的换行也会增加行号。差额为 A − B，仅一侧有的编号以另一侧金额为 0。合计是两份账单各自金额之和。

页面每页最多显示 100 笔，可筛选、查找编号和翻页。页面筛选不影响导出：「全部差异」含三个差异类别；「全部结果」另外包含一致记录。

导出为 UTF-8 BOM、CRLF，中文可在常见表格软件中识别。为防止 CSV 公式注入，编号始终加前置单引号，危险前缀的单元格（含负数、正号差额）也加单引号。相应单元格作为文本，部分软件可能显示单引号；后续计算需在可信本地环境中人工转换。不要自动移除不可信编号的保护符。导出只有复核字段，不复制备注列，不替代原始账单。

文件没有上传，没有银行 / AI API，没有遥测，没有账号、服务器月费和第三方库。页面 CSP 禁止连接网络；应用源文件也没有网络调用。不自动访问未选择的文件。浏览器本身的后台行为不属于应用代码。

## 开发验证

运行 `node --test tests/core.test.cjs` 和 `node tests/review-fuzz.cjs`。包含金额精度、格式验证、导出保护、10,000 条边界和 2,000 组固定种子的 CSV 往返解析测试。合成样例及预期结果位于 `examples/`。

导出结果是人工复核清单，不能作为原账单往返再导入，不支持自动修正或合并账务。实际业务规则与结果仍须人工复核。
